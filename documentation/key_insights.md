# CogniStream — Key Insights and Interpretation

## 1. Project Overview

CogniStream is an analytics project that explores simulated developer activity patterns and activity-based indicators related to focus sessions and context switching.

The dataset is entirely synthetic and represents:
- 30 fictional developers.
- 15,000 activity records.
- 1,920 daily developer records.
- A simulation period from 1 January 2026 to 31 March 2026.
- Six activity categories: Coding, Code Review, Debugging, Testing, Documentation and Meeting.

The analysis follows three stages:
1. Univariate analysis
2. Bivariate analysis
3. Multivariate analysis using Principal Component Analysis (PCA)

## 3. Bivariate Analysis — Relationships Between Variables

Pearson and Spearman correlation analyses were used to examine relationships between selected numerical variables.

### Key Observations

- Total focus-active minutes and average focus-session duration show a strong positive correlation (Pearson: 0.899).
- Average focus-session duration and longest focus-session duration show a positive correlation (Pearson: 0.714).
- Total activity minutes and total focus-active minutes show a moderate positive correlation (Pearson: 0.628).
- Unique activity types and context switches show a moderate positive correlation (Pearson: 0.465).

### Group Comparisons

- Backend has the highest mean daily activity duration among the simulated teams (approximately 296.57 minutes).
- DevOps has the lowest mean daily activity duration (approximately 290.29 minutes).
- Average focus-session counts are similar across teams.
- Intermediate developers have the highest mean daily activity duration among the experience groups (approximately 293.16 minutes).

The differences between these groups are descriptive and relatively small. They do not establish that one team or experience group is more productive.

### Activity Duration by Category

Mean activity duration ranges from approximately:
- Code Review: 37.71 minutes.
- Testing: 37.08 minutes.

The average durations are very similar across all six activity categories.

## 4. Multivariate Analysis — Principal Component Analysis

PCA was applied to seven standardized numerical variables:

- Unique activity types
- Context switches
- Meeting count
- Total activity minutes
- Total focus-active minutes
- Average focus-session duration
- Longest focus-session duration

### Explained Variance

| Component | Explained Variance | Cumulative Variance |
|---|---:|---:|
| PC1 | 48.3% | 48.3% |
| PC2 | 21.4% | 69.7% |
| PC3 | 15.0% | 84.7% |
| PC4 | 7.8% | 92.5% |
| PC5 | 5.4% | 97.9% |
| PC6 | 1.7% | 99.6% |
| PC7 | 0.4% | 100.0% |

The first two principal components explain 69.7% of the total variance. The first three explain 84.7%.

The first two components provide a useful reduced representation of the data, but 30.3% of the total variance remains unexplained by these two components.

### Component Interpretation

- PC1 is strongly associated with activity and focus-session duration variables.
- PC2 is mainly associated with unique activity types and context switches.
- Meeting count has a loading in the opposite direction to total activity and focus-duration variables on PC1.

These components summarize variation among the selected variables. They are not direct measurements of productivity, flow state or cognitive load.

## 5. Important Data Limitations

The following limitations must be considered when interpreting the results:

1. **Synthetic Data:** All records represent simulated developers and activities. The findings cannot be generalized to real employees or workplaces.

2. **Proxy-Based Indicators:** Focus sessions and context-switching metrics are generated using predefined simulation rules. They do not directly measure a person's attention, cognitive load or psychological state.

3. **Constant Gap Metrics:** The variables `gaps_5min_or_more`, `minutes_in_gaps_5min_or_more` and `longest_gap_minutes` are constant across records. They provide no useful variation for correlation or group comparisons.

4. **Duplicate Focus Measures:** `total_focus_elapsed_minutes` and `total_focus_active_minutes` contain identical values. They should not be treated as independent indicators.

5. **Mathematical Relationships:** Some focus-related metrics are structurally related. Strong correlations between them may partly result from how the metrics are calculated.

6. **Correlation Does Not Imply Causation:** The analysis identifies associations, not cause-and-effect relationships.

7. **PCA Limitations:** PCA is influenced by the variables selected and their relationships. Component loadings should be interpreted in the context of the simulation design.

8. **Outlier Interpretation:** Potential outliers identified through the Interquartile Range (IQR) method are statistical flags and do not necessarily indicate errors. Their interpretation should consider the simulation rules and metric distributions.

---

## 6. Recommendations for Improving the Analysis

- Introduce more varied and independently defined simulation rules for future datasets.
- Review constant and mathematically duplicated variables before conducting statistical analysis.
- Clearly document how each metric is generated and what it represents.
- Avoid interpreting activity-based proxies as direct measures of human productivity or mental states.
- If future research uses real-world data, ensure appropriate consent, privacy protections and ethical review.

---

## 7. Overall Conclusion

The exploratory analysis demonstrates how synthetic activity records can be transformed into daily metrics and examined through univariate, bivariate and multivariate techniques.

The analysis identifies patterns in activity duration, activity variety, context switching and simulated focus-session metrics. Correlation analysis highlights relationships among selected variables, while PCA provides a reduced representation of the multivariate dataset.

The main outcome of CogniStream is an end-to-end analytical workflow covering synthetic data generation, data processing, exploratory analysis, statistical relationships and dimensionality reduction.

All findings remain limited to the assumptions and rules used to generate the synthetic dataset.
