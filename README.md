# CogniStream-Developer-Flow-State-Cognitive-Load-Analytics
1. Project Overview

1.1 Project Title

CogniStream: Developer Flow-State & Cognitive Load Analytics

1.2 Introduction

Software developers often work on complex tasks that require sustained concentration, problem-solving, and continuous decision-making. Their productivity can be influenced by several factors, including coding time, interruptions, sleep, workload, and the use of AI-powered development tools. Frequent interruptions and excessive cognitive demands may affect a developer's ability to maintain focus and complete tasks successfully.

CogniStream is a data analytics project designed to explore the relationship between developer productivity, work patterns, interruptions, and cognitive load. The project uses developer productivity data to identify patterns and examine how factors such as coding hours, distractions, commits, reported bugs, sleep duration, and AI usage relate to cognitive load and task success.

The project will also introduce a simulated event dataset containing coding-session timestamps and interruption details. This additional dataset will support exploratory analysis of event timing and interruption patterns, which cannot be examined directly using the original dataset because it does not contain timestamps or detailed event records.

By combining productivity metrics with clearly labelled simulated event data, CogniStream aims to demonstrate how data analytics can help understand developer work patterns and support more informed decisions about improving focus and workflow efficiency.

1.3 Problem Statement

Developer productivity cannot always be understood through coding hours or completed tasks alone. Factors such as distractions, cognitive load, sleep patterns, bug reports, and AI tool usage may also be relevant to understanding work performance.

However, productivity datasets may not contain detailed information about when coding sessions occur or when interruptions happen. This limits the ability to investigate time-based work patterns and interruption behaviour.

CogniStream addresses this analytical challenge by examining the available productivity data and creating a separate simulated dataset for coding sessions and interruption events. The project will use exploratory data analysis and visualisation to identify patterns, investigate relationships between variables, and communicate findings through an interactive dashboard.

1.4 Project Objectives

The main objectives of CogniStream are:

Developer Productivity Analysis: Examine coding hours, commits, bug reports, and task success to understand developer work patterns.

Cognitive Load Analysis: Investigate how cognitive load varies across different productivity and work-related measures.

Interruption Analysis: Explore the recorded distraction measure and use simulated interruption events to demonstrate time-based interruption analysis.

Sleep and Work Pattern Analysis: Examine the relationship between sleep duration, coding hours, and other available productivity indicators.

AI Tool Usage Analysis: Investigate how AI usage hours relate to coding activity, cognitive load, and task success.

Coding Session Analysis: Generate simulated coding-session start and end times to demonstrate session-duration and time-based analysis.

Interactive Dashboard Development: Present important metrics, patterns, and analytical findings through an interactive dashboard.

Decision Support: Use the findings to develop evidence-based suggestions for understanding work patterns and identifying areas for further investigation.
